<p>リード文。記事を開いた人が最初に読む2〜3行。何の話で、読むと何が分かるかを書く。</p>

<h2>見出し</h2>
<p>本文の段落。</p>

<h2>Marketikの見方</h2>
<p>ここが一番大事。一般論ではなく、自社の現場で起きたこと・数字・失敗談を書く。
AIには書けない部分であり、Googleが評価する Experience（経験）にあたる。</p>

<h2>まとめ</h2>
<p>要点の再掲と、相談への導線。</p>

書くときのルール

slug
  半角の英小文字・数字・ハイフンのみ。日本語を入れるとURLが文字化けする。
  使えない語: blog / service / contact / works / member / privacy-policy
              thanks / category / tag / author / page / feed / wp-admin
  数字のみ（例: 2026）も不可。年月アーカイブと衝突する。

category
  ニュース / ノウハウ / 実績・事例 のいずれか。既存のものと完全一致させる。

本文
  HTMLで書く。使うのは <p> <h2> <h3> <ul><li> <strong> <a> 程度で足りる。
  <h1> は使わない（タイトルが自動で h1 になるため）。

必ず入れるもの
  自社の一次情報を最低1つ。運用した数字、現場で気づいたこと、よく聞かれる質問など。
  他社記事のまとめだけの記事は書かない。
